# Simple Calculator (Console Application)

A simple **Core Java console-based Calculator** that performs basic arithmetic operations such as addition, subtraction, multiplication, division, and modulus. This project demonstrates user input handling, switch expressions, conditional logic, and arithmetic operations in Java.

---

## Features

- Perform addition, subtraction, multiplication, division, and modulus operations
- Accept user input through the console
- Uses Java switch expressions for operation selection
- Handles division by zero
- Displays the calculated result instantly
- Beginner-friendly console application

---

## How It Works

1. The program prompts the user to enter the first number.
2. The user selects an arithmetic operator (`+`, `-`, `*`, `/`, `%`).
3. The user enters the second number.
4. The program evaluates the selected operation using a switch expression.
5. If division is selected, the program checks for division by zero.
6. The calculated result is displayed on the console.

---

## Installation & Usage

Compile the program:

```bash
javac Calculator.java
```

Run the program:

```bash
java Calculator
```
